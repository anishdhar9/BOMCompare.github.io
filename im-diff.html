How it works
  • This page compares two exports of the SAME Item Master BOM. It does not compare against CAD. Use it to review what changed between two releases of the same project.
  • Match key: part number, not case-sensitive. Row Order (the dotted position path) is not used to match parts across the two files, since it can shift between releases even when a part itself did not change.
  • Added: part numbers present in the newer file but not the older one.
  • Removed: part numbers present in the older file but not the newer one.
  • Changed: part numbers present in both, where Quantity, Revision, Material, Title, Description, or State differs. Material is compared with the same naming-convention normalization the main BOM Compare tool uses (DIN vs AISI grade, spacing, language), so a part written differently but chemically the same material is not reported as changed.
  • ECR sheet: fills this organization's ECR (Engineering Change Request) template from a separate, hierarchical (position-aware) tree diff of the two files — a part is compared against its counterpart at the SAME position in the BOM, not just any row sharing its part number, so a part reused under several parents gets one row per parent that actually changed. "Item No. With Rev" fuses the part number with its raw revision value (unpadded) on a Drg. Revised/Drg. Obsolete row; other actions use the bare part number. A revision bump becomes an old-row/new-row pair — Drg. Revised (new rev, 0→1) then Drg. Obsolete (old rev, 1→0) — both referencing the parent's CURRENT revision. Action (Part Added, Part Deleted, Qty Changed, Drg. Obsolete, Drg. Revised) is derived automatically; the "PN" header field is filled from the project key when available. Reason Code and the rest of the form's header fields need your own judgment, so they are left blank. A part whose only change is Material, Title, Description, or State has no matching Action code, so it is reported separately instead of being turned into a row. This is a complete structural diff, not scoped to any one engineering change narrative — remove rows unrelated to the change you're filing before submitting.
